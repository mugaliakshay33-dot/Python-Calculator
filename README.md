## Python Calculator

A simple command-line calculator built using Python that performs basic arithmetic operations. This project is beginner-friendly and demonstrates the use of functions, conditional statements, exception handling, and user input in Python.

## Features
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Handles division by zero
Validates numeric input
Displays an error message for invalid operators
Simple and user-friendly command-line interface
🛠️ Technologies Used
Language: Python 3
Concepts: Functions, conditional statements, user input, and exception handling

## Prerequisites

Make sure Python 3 is installed on your system.

Check your Python version using:

python --version


Or:

python3 --version

## Getting Started
1. Clone the repository

2. Navigate to the project directory
cd python-calculator

3. Run the program
python calculator.py


If your system uses python3, run:

PythonCalculator.py

## Usage
Enter the first number.
Enter the desired arithmetic operator (+, -, *, or /).
Enter the second number.
View the result in the terminal.

## Example Output
=== Python Calculator ===
